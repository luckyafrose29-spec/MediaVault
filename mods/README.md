# Mods folder

আপনার mod JAR এখানে upload করে রাখতে পারেন, কিন্তু বর্তমান server **Paper 26.3** — Paper Fabric, Forge বা NeoForge mod load করে না। শুধু এই folder-এ JAR রাখলে mod বা Playit tunnel চালু হবে না।

আপনার Playit file-এর নাম বা download link দিন, যাতে সেটি Paper plugin নাকি Fabric/Forge/NeoForge mod এবং Minecraft 26.3-এর সঙ্গে compatible কি না বোঝা যায়। Mod loader লাগলে server বদলাতে হবে।

Paper 26.3-compatible plugin হলে সেটি `../plugins/` folder-এ রাখুন। অন্য বিকল্প হলো আলাদা Playit agent চালানো; মূল README-র tunnel নির্দেশনা দেখুন।

এই folder-এর uploaded files Git-এ commit হয় না; আলাদা backup রাখুন। শুধু বিশ্বস্ত উৎসের JAR ব্যবহার করুন।
