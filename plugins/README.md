# Paper plugins

Paper 26.3-compatible plugin JAR server বন্ধ অবস্থায় এই folder-এ upload করুন, তারপর `./start.sh` চালান। কেবলমাত্র বিশ্বস্ত উৎসের plugin ব্যবহার করুন। প্লাগিনটি Minecraft 26.3 এবং Paper support করে কি না আগে যাচাই করুন।

Fabric, Forge ও NeoForge mod এখানে কাজ করবে না। Playit tunnel চালু করতে plugin-এর নিজস্ব setup অনুসরণ করুন; শুধু upload করলেই tunnel তৈরি হয়েছে ধরে নেবেন না। বিকল্প হিসেবে মূল README অনুযায়ী আলাদা Playit agent চালাতে পারেন।

Plugin files ও generated data Git-এ commit হয় না। Plugin configuration-এ secret থাকতে পারে, তাই backup গোপন রাখুন।
